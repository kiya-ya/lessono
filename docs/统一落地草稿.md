### I. 已成团天数口径修正（本轮新发现，改后端查询）⭐

> 现象：08-12 成立 / 08-16 解散的团，明细「已成团天数」显示 6，实际应为 4。
> 根因：`days_since_formed` 是爬虫从 bigdata「已成团天数」列原样照抄的「成团第 N 天」（含头 +1），且已解散团会在快照里残留一两天、天数继续涨到快照日（08-17 显示 6）。

1. 已解散团（`dissolve_date` 非空）：`已成团天数` 改为 `dissolve_date − form_date`（真实存活天数），不再用 raw `days_since_formed`。
2. 进行中团：沿用 bigdata 实时值（「第 N 天」口径，与 bigdata 一致）。
3. 覆盖所有展示 `days_since_formed` 的位置：明细搜索表（`/api/detail`）、姐姐画像带团明细（`/api/sister-detail`）、存活分析、团详情弹窗。
4. 附带确认（非 bug，不改）：同一妹妹可被反复配对（团解散后原班人马重新成团、新团 ID）；妹妹中途改昵称是正常业务。可选优化——姐姐画像「妹妹」列加 UID，避免同名/改名被误读成多个人。
