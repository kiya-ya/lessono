# 文档导航

本目录存放项目文档。现行**权威入口只有两份**（都在项目根目录），其余均为历史归档。

## 现行文档（以这四份为准）

| 文档 | 位置 | 读者 | 说明 |
|------|------|------|------|
| **README.md** | 项目根目录 | 所有人 | 唯一入口：功能特性 / 技术栈 / 部署 / 项目结构 / 版本历史 / 常见问题 |
| **项目上下文记忆.md** | 项目根目录 | AI 开发 | 数据库结构、接口清单、排障记录、口径备忘（非产品文档） |
| **CONTEXT.md** | 项目根目录 | AI 开发 | 领域术语表（姐妹团/姐姐/妹妹/培养力/候选池等），不含实现细节 |
| **docs/adr/** | docs/adr/ | AI 开发 | 架构决策记录（编号 ADR，记录「为什么这么设计」） |

## 约定

- 新增 / 改动功能：更新根目录 `README.md` 的「功能特性」与「版本历史」。
- 排障记录 / 数据口径 / 接口变更：更新根目录 `项目上下文记忆.md`。
- 不再新增单独的 PRD / 进度 / 完成度文档——当前状态一律以 `README.md` 版本历史为准。
