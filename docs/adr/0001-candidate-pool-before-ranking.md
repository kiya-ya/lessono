# 先建候选池与结果记录，再做权威排序

姐妹团看板要回答的核心决策是「该把资源倾斜给哪个姐姐」。我们曾想直接做「培养力」分数并据此排序（方案 A），但系统是首次开发、没有任何「输送/提拔后效果好」的成功案例可回看，分数权重只能拍脑袋。于是决定先做候选池 + 结果记录（方案 B），攒出成功案例后再演进到权威排序（方案 A）。培养力暂定为四因子：留存 = 妹妹成长 > 共同成长 > 牌子等级（牌子等级是准入门槛）。

## Considered Options

- **A. 直接排序**：给运营一个「倾斜给前 3 名」的权威榜单。被否——分数未经验证，运营不敢照着做，等于把没依据的算法包装成权威。
- **B. 候选池 + 结果记录（选定）**：并列展示候选与四因子证据，同时记录每次「输送妹妹 / 提拔管理」的动作与结果，3 个月后据成功案例学习权重，再演进到 A。

## Consequences

- 下一步不是打磨分数算法，而是先落地两样：①候选池（并列展示四因子证据，不假装懂权重）；②结果记录（新增记录动作的表；动作发生在点点开黑平台、不在看板内，需人工或定期回填）。
- 培养力权重暂为拍脑袋（留存 = 妹妹成长 > 共同成长 > 牌子等级），在成功案例足够前不做成权威排序。
- 四个因子从 `team_detail`（逐日快照）与 `team_sister_revenue`（周流水）可算，无需新数据源；仅「结果记录」需要新表。
